# Política de seguridad

## Cómo reportar una vulnerabilidad

Repórtala **en privado** con GitHub Security Advisories: pestaña **Security** del repositorio, **Report a vulnerability**. No abras un issue público.

Incluye la versión o commit afectado, el componente (paquete, PWA o servidor), los pasos para reproducir y el impacto que esperas.

**No adjuntes fotos, escaneos ni datos personales** de documentos reales (tuyos ni de terceros). Para demostrar el problema usa los fixtures sintéticos del repositorio (`packages/fixtures`, `evals/fixtures`). Si un reporte llega con datos personales, se borra y se pide uno nuevo sin ellos.

## Alcance

Este proyecto es una librería de código abierto (MIT). Los autores no operan instancias de terceros ni tratan sus datos: los incidentes de una instancia desplegada los atiende quien la despliega, como Responsable del tratamiento (ver `README.md` y `docs/legal/README.md`).

## Respuesta

Se acusa recibo en cuanto sea posible y se coordina la divulgación con quien reporta. No hay programa de recompensas.
