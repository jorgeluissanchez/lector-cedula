# @lector-cedula/angular

Adaptador Angular (>= 18, con y sin zone.js) del lector headless: injectLectorCedula con signals, sin UI (sdk-integracion, SDK-32, SDK-34).

## Instalación

```sh
npm install @lector-cedula/angular
```

Documentación, uso y despliegue: [README del repositorio](https://github.com/jorgeluissanchez/lector-cedula/blob/main/README.md).
