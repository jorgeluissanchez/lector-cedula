# @lector-cedula/web

Núcleo headless del lector de cédula colombiana: crearLector (máquina de estados sin UI), leerDocumento, carga verificada y offline del motor (cambio sdk-integracion).

## Instalación

```sh
npm install @lector-cedula/web
```

Documentación, uso y despliegue: [README del repositorio](https://github.com/jorgeluissanchez/lector-cedula/blob/main/README.md).
