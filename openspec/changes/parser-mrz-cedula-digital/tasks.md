# Tasks

Todas las tareas siguen TDD (principio II): la prueba se escribe con los literales del escenario, se ve fallar y luego se implementa. Datos sintéticos únicamente (skill `fixture-sintetico`); el único dato no generado es el ejemplo sintético público de Eitol (MZ-20). Cada `it` empieza por el ID del requisito. Comandos: `V` = `npx vitest run packages/parsers`; `C` = `npx vitest run packages/parsers --coverage --coverage.include=packages/parsers/src/icao-9303.ts --coverage.include=packages/parsers/src/mrz-cedula-digital.ts`; `M` = `npm run test:mutacion`; `E` = `npm run eval:quick`. API, módulos y tipos: `design.md`, decisión 2. Toda tarea termina con `npm run check` en verde además de su comando propio.
